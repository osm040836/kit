# 작업 가이드

제한된 시간에 개발할 때 사용하는 일반적인 작업 지침과 기록 양식입니다. 특정 과제의 문제, 결과물, 개인 정보는 포함하지 않습니다.

## 파일 구성

- `AGENTS.md`: AI 코딩 에이전트의 기본 작업 지침
- `guide.md`: 긴 로그 관리 방법과 막혔을 때 쓰는 요청문
- `checklist.md`: 제출 전 확인 사항과 이해 점검
- `notes.md`: 진행 상황을 짧게 기록하는 빈 양식

## 사용 방법

사용하는 환경에서 외부 공개 자료를 가져오는 것이 허용되는지 먼저 확인합니다. 허용된 환경에서는 해당 환경의 도구로 이 자료를 가져옵니다. 이 폴더를 프로젝트 전체에 덮어쓰지 않습니다.

`AGENTS.md` 자동 적용 여부는 실행 도구와 파일 위치에 따라 다릅니다. 자동 적용되지 않으면 에이전트에게 파일 경로를 지정해 읽도록 요청합니다. 기존 프로젝트 지침과 충돌하는 부분은 적용 전에 확인합니다.

`AGENTS.md`는 다른 파일 없이 단독으로 사용할 수 있습니다. `guide.md`는 추가 설명과 예시입니다. 기존 `AGENTS.md`가 있는 프로젝트에서는 덮어쓰지 말고 필요한 지침만 통합합니다.

모델·서브에이전트 선택을 지원하지 않는 환경에서는 `모델과 위임` 섹션을 생략해도 됩니다. 지원 여부를 이미 확인했다면 다시 조사하지 않습니다.

예시 요청:

> ~/workspace/AGENTS.md를 지침으로 적용해줘. 기존 프로젝트 지침과 현재 환경 규칙을 우선해줘. 시작 절차대로 README·과제 안내·제출 문서 양식을 읽고 요구사항 표, 확인 필요 질문 목록, PLAN.md를 만들어줘.

## 기록과 공개 범위

이 저장소는 일반 지침 배포용입니다. 실제 작업 기록은 별도 작업 공간에 작성합니다. 문제, 코드, 데이터, 로그, 인증 정보, 개인 링크를 이 저장소에 올리지 않습니다. 기록 양식 자체를 공개하는 것과 작성된 기록을 공개하는 것은 다릅니다.

실제 진행 메모는 작업 공간의 `NOTES.md`에 작성하며 Git 무시 대상으로 지정하지 않습니다. 제출 규칙이 허용하면 제출물에 포함합니다. 공개용 지침 저장소와 제출용 작업 공간은 구분합니다. Git에서 무시되지 않는 새 파일도 자동으로 추적되지는 않으므로, Git을 사용한다면 상태를 확인합니다.

공개 저장소는 검색되거나 복제될 수 있습니다. 평범한 파일 이름은 비공개 설정을 대신하지 않습니다. 공개 유지 조건이 있는 환경에서는 해당 조건을 따릅니다.
